# BOOTS IT HELPDESK — ระบบเปิดงาน Ticket (หลายผู้ใช้)

โปรแกรมติดตั้งบน **เครื่อง Server เครื่องเดียว** — เครื่องลูกทุกเครื่อง
**ไม่ต้องติดตั้งอะไรเลย** ใช้แค่เบราว์เซอร์ และทุกคน Login ด้วยบัญชีของตัวเอง

> **เวอร์ชันนี้แก้บั๊ก** `sqlite3.OperationalError: no such column: created_by`
> ที่เกิดกับฐานข้อมูลจากเวอร์ชันก่อน ตอนนี้ระบบจะอัปเกรดฐานข้อมูลเดิมให้อัตโนมัติ
> **ข้อมูลเก่าไม่หาย**

---

## เครื่องลูกใช้งานยังไง

```
        เครื่อง Server (ติดตั้งโปรแกรม + เก็บข้อมูล)
                        |
     +----------+-------+-------+----------+
  เครื่องลูก 1  เครื่องลูก 2  เครื่องลูก 3   มือถือ
   Login: sarita  Login: nattawut  Login: sunita  Login: mayjaree
```

เครื่องลูกทำแค่ 2 อย่าง — เปิดเบราว์เซอร์ แล้วพิมพ์ `http://<IP ของ Server>:8080` → Login

---

## ส่วนที่ 1 — ติดตั้งบนเครื่อง Server (ทำครั้งเดียว)

| ลำดับ | ไฟล์ | ทำอะไร |
|---|---|---|
| 1 | `1_SETUP_PYTHON.bat` | ติดตั้ง Python แบบพกพา (ไม่ต้องใช้สิทธิ์แอดมิน) |
| 2 | `2_START_SERVER.bat` | เปิดระบบ |
| 3 | `3_IMPORT_OLD_DATA.bat` | ลากไฟล์ Excel เดิมใส่ นำเข้าข้อมูลเก่า |
| 4 | `4_AUTO_START_AND_FIREWALL.bat` | **คลิกขวา → Run as administrator** |

### ข้อ 4 สำคัญที่สุด — ถ้าไม่ทำ เครื่องลูกจะเข้าไม่ได้

- เปิดช่อง Firewall พอร์ต 8080 ให้เครื่องอื่นเข้ามาได้
- ตั้งให้ระบบเปิดเองอัตโนมัติทุกครั้งที่ Server บูต

### ไฟล์ช่วยเหลือเพิ่มเติม

| ไฟล์ | ใช้เมื่อไหร่ |
|---|---|
| `0_CHECK_SYSTEM.bat` | ดู IP ของ Server + เช็กสถานะ Firewall |
| `9_REPAIR_DATABASE.bat` | ใช้เมื่อขึ้น error เกี่ยวกับฐานข้อมูล (สำรองไฟล์เดิมให้ ไม่ลบทิ้ง) |

---

## ส่วนที่ 2 — สร้างบัญชีให้ทีม

1. เปิด `http://<IP ของ Server>:8080`
2. Login ด้วย **admin / admin123**
3. ระบบบังคับเปลี่ยนรหัสผ่านทันที
4. เมนู **ผู้ใช้งาน** → กรอกช่อง "เพิ่มผู้ใช้ใหม่" → กด **สร้างบัญชี**

**ผู้ใช้ใหม่ทุกคนถูกบังคับเปลี่ยนรหัสผ่านเองตอน Login ครั้งแรก**

| สิทธิ์ | ทำอะไรได้ | เหมาะกับ |
|---|---|---|
| **ผู้ดูแลระบบ** | ทุกอย่าง + จัดการผู้ใช้ + ลบงาน | หัวหน้าทีม |
| **เจ้าหน้าที่ Helpdesk** | เปิดงาน แก้ไขงาน ดูรายงาน | ทีม Helpdesk |
| **ดูอย่างเดียว** | ดูอย่างเดียว แก้ไขไม่ได้ | ผู้บริหาร |

---

## ส่วนที่ 3 — วิธีใช้ของทีม

**เครื่องลูก:** เปิดเบราว์เซอร์ → `http://<IP ของ Server>:8080` → Login → Bookmark ไว้

**มือถือ:** เปิดเบราว์เซอร์ → ที่อยู่เดียวกัน → Login → กด "เพิ่มไปยังหน้าจอโฮม"

**นอกออฟฟิศ:** ต่อ VPN บริษัทก่อน (คอม = GlobalProtect / มือถือ = MS Defender Tunnel)
แล้วเปิด URL เดิม

---

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| **ขึ้น `no such column`** | แก้แล้วในเวอร์ชันนี้ ระบบอัปเกรดฐานข้อมูลเองอัตโนมัติ ถ้ายังไม่หายให้รัน `9_REPAIR_DATABASE.bat` |
| **เครื่องลูกขึ้น `ERR_CONNECTION_TIMED_OUT`** | Firewall บล็อก หรือคนละวง LAN — รัน `4_AUTO_START_AND_FIREWALL.bat` แบบ admin ก่อน แล้วลอง `ping <IP Server>` จากเครื่องลูก |
| **ขึ้น `ERR_CONNECTION_REFUSED`** | Server ปิดอยู่ หรือยังไม่ได้รัน `2_START_SERVER.bat` |
| IP เปลี่ยนบ่อย | ขอทีม Network ตั้ง Fixed IP ให้ Server |
| ลืมรหัสผ่าน | ผู้ดูแลเข้าเมนู **ผู้ใช้งาน** → เลือกคนนั้น → ตั้งรหัสใหม่ |
| พนักงานลาออก | เมนู **ผู้ใช้งาน** → เปลี่ยนสถานะเป็น **ปิดใช้งาน** (งานเดิมยังอยู่) |
| ขึ้น `Cannot start on port 8080` | เปิด Command Prompt ในโฟลเดอร์ `app` พิมพ์ `python server.py 9000` |

## การสำรองข้อมูล

ข้อมูลอยู่ที่ `app\data\boots_helpdesk.db` บนเครื่อง Server เท่านั้น

ให้ทีม IT ตั้ง Scheduled Task สำรองทุกคืน:
```
xcopy "C:\boots_ticket_system\app\data" "\\backup-server\BOOTS\%date%\" /I /Y
```

**ห้ามวางโฟลเดอร์ `data` ไว้ใน OneDrive/SharePoint ที่ sync เด็ดขาด** ไฟล์จะพัง
